Windows setup

Download WiFind

Install Npcap first, then run the WiFind setup as Administrator. WiFind opens a local dashboard and scans your Wi-Fi/LAN with ARP.

WiFind releases Download Npcap

Install checklist

  1. Install Npcap from the official site.
  2. Download WiFind-Setup.exe.
  3. Run WiFind as Administrator.
01

Npcap required

Windows needs Npcap so WiFind can send ARP packets through your active network adapter.

02

Local dashboard

The app runs on your machine and opens a browser UI at localhost.

03

Private inventory

Aliases, scan history, and snapshots stay in local app storage.
