Install WiFind

Download the Windows setup

WiFind needs Administrator privileges and Npcap because it sends ARP packets through the local network adapter.

Latest GitHub release Install Npcap

For users

  1. Install Npcap.
  2. Download `WiFind-Setup.exe` from the latest GitHub release.
  3. Run the setup installer.
  4. Launch WiFind as Administrator.

For maintainers

  1. Run `.\packaging\windows\build_windows.ps1` for a portable executable.
  2. Run `.\packaging\windows\build_windows.ps1 -Installer` for an installer.
  3. Upload `dist\WiFind.exe` or `dist\installer\WiFind-Setup.exe` to GitHub Releases.
  4. Update the release link on this page after setting the repository URL.

Release downloads

Install Npcap first, then download the latest WiFind setup from the release page. WiFind stores aliases and scan history locally on your machine.
