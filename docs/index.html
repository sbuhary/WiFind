Built for local diagnostics

Smarter than a ping sweep

ARP discovery

Broadcasts ARP requests on the selected subnet and streams each discovered device into the dashboard.

Cache enrichment

Merges live replies with the operating system ARP cache to surface neighbors that missed the live scan window.

Identity hints

Resolves vendors, hostnames, gateway candidates, private MACs, source labels, and confidence scores.

Local inventory

Saves aliases, first seen, last seen, seen count, and last known identity data on the scanning machine.

How it works

Press Smart Scan and watch the inventory build

  1. Detect the active Wi-Fi adapter and local subnet.
  2. Read local neighbor cache entries.
  3. Send live ARP probes and append replies immediately.
  4. Enrich results with hostnames, vendors, device type, confidence, and history.
